# M Cluster

The light version of [Cluster Themes](../cluster_themes/README.md), made for the owner's car: one theme, **M-style**
(an M8's cluster: shift lights, boost and temperatures), shown in **Sport and Sport Plus**. In Comfort, Eco Pro and
every other mode BMW's own cluster stays untouched, with Waze on Cluster's map.

Same engine as Cluster Themes (`shared/hud.js`), without the other 13 themes, the Waze map inside the theme, the badge,
alerts, G-meter, holiday lights, demo and the media state. Nothing of it stays on the cluster outside Sport unless
**M ready in the background** is turned on (instant switch, but it keeps the theme loaded in cluster-render).

**Install one or the other:** M Cluster and Cluster Themes both draw the whole cluster.
